# Overtone

<!-- generated:begin — rhizome-docs rewrites this block; write outside it -->
Adds layers made from the sound itself: an octave down, an octave up and a fifth up.

| Control | Range | Default | What it does |
|---|---|---|---|
| Overtone | on or off | on | Adds layers made from the sound itself: an octave down, an octave up and a fifth up. |
| Mix | 0 to 1 | 0 | How much of the added layers is blended with the original sound. |
| Sub | 0 to 1 | 0.5 | How loud the layer an octave down is. |
| Octave | 0 to 1 | 0.3 | How loud the layer an octave up is. |
| Fifth | 0 to 1 | 0 | How loud the layer a fifth up is. |
| Tone | 500 Hz to 16000 Hz | 5000 Hz | Where the highs of the layers are rolled off. |
