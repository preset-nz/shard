# Shifter

<!-- generated:begin — rhizome-docs rewrites this block; write outside it -->
Moves every frequency by the same number of hertz, so the sound turns inharmonic: clangs, spirals and detuned shimmer.

| Control | Range | Default | What it does |
|---|---|---|---|
| Shifter | on or off | on | Moves every frequency by the same number of hertz, so the sound turns inharmonic: clangs, spirals and detuned shimmer. |
| Mix | 0 to 1 | 0 | How much shifted sound is blended with the original. |
| Shift | -2000 Hz to 2000 Hz | 0 Hz | How far every frequency moves, in hertz; negative moves them down. |
| Feedback | 0 to 0.95 | 0 | Sends the shifted sound round again, for a rising or falling spiral. |
| Spread | 0 to 1 | 0 | Shifts the left and right sides in opposite directions, for width. |
