# Envelope

<!-- generated:begin — rhizome-docs rewrites this block; write outside it -->
Shapes how each note swells in and dies away; at its neutral setting it passes the sound untouched.

| Control | Range | Default | What it does |
|---|---|---|---|
| Envelope | on or off | on | Shapes how each note swells in and dies away; at its neutral setting it passes the sound untouched. |
| Mix | 0 to 1 | 1 | How much of the shaped sound replaces the unshaped one; zero leaves the sound untouched. |
| Attack | 0 ms to 4000 ms | 0 ms | How long the sound takes to rise from silence to full level. |
| Decay | 0 ms to 4000 ms | 0 ms | How long the sound takes to fall from full level to Sustain. |
| Sustain | 0 to 1 | 1 | The level held after the decay, until the note is released. |
| Release | 0 ms to 4000 ms | 0 ms | How long the sound takes to fade to silence once the note ends. |
